The repo check

When you paste a repo, our server fetches that public GitHub repository from GitHub. It keeps only the files the check reads (code, package files, workflows, Dockerfiles), checks them and deletes them in the same request. To compare versions, it looks up the package names it found on the npm registry, PyPI and deps.dev (run by Google). Only package names are sent, never code. Nothing from the repo is stored.

The result is about the public repo, not about you. It is cached for up to 1 hour. After that, an older result may be shown for up to 24 more hours while a fresh one is made. The repo name also appears in the server logs above.

README badges

A badge is an image of a public repo's check result. Browsers cache it for up to 1 hour and our host for up to 6 hours, with an older copy possibly shown for up to 24 more hours while it refreshes. On GitHub, README images load through GitHub's own image proxy, so we don't see who views a README.

The tools

The npm package oneshot-agent, the MCP server, the Claude Code plugin and the GitHub Action run on your machine or in your CI. They send no telemetry and no code. To get today's facts, they read public sources:

  • oneshotagent.dev/facts.json, or its fallback address oneshot-tawny.vercel.app (the same Vercel project). These requests are logged like any request to this site.
  • The npm registry, PyPI, endoflife.date and GitHub's public API.
  • deps.dev (run by Google), when you ask about a package. Only the package name is sent.

You can turn off the request to our site with ONESHOT_FACTS_URL=off.
