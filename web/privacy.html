OneShot

Privacy

Last updated 27 November 2026.

Short version
  • No cookies, no analytics, no tracking, no accounts, no ads.
  • The tools (CLI, MCP server, plugin, GitHub Action) send no telemetry.
  • The repo check downloads a public repo, checks it and deletes it straight away.
  • Our host keeps normal server logs, like every website.

Who runs OneShot

OneShot is an open-source project maintained at github.com/borossdaniel/OneShot. For any privacy question or request, open an issue. If you'd rather not ask in public, open an issue asking for a private contact and we'll reply there.

This website

The site is hosted by Vercel. Like any web server, Vercel records technical data for each request: your IP address, the page or address requested, the time, and your browser's user agent. These logs are kept for a limited time, to deliver the site and keep it secure. That is the legal basis (legitimate interest, GDPR Art. 6(1)(f)). We don't combine the logs with anything, and we don't use them to identify visitors.

Fonts and everything else on the page are served from this site. Your browser doesn't contact Google or any other third party when you visit.

The repo check

When you paste a repo, we fetch that public GitHub repository from GitHub, keep only the files the check reads (code, package files, workflows, Dockerfiles), check them and delete them in the same request. Nothing from the repo is stored. The result is about the public repo, not about you. It is cached for up to an hour, so the next person checking the same repo gets it faster. The repo name also shows up in the server logs above.

README badges

A badge is an image of a public repo's check result, cached for up to 6 hours. On GitHub, README images are loaded through GitHub's own image proxy, so we don't see who views a README.

The tools

The npm package oneshot-agent, the MCP server, the Claude Code plugin and the GitHub Action run on your machine or in your CI. They send no telemetry and no code. To get today's facts, they read public sources: the npm registry, PyPI, endoflife.date, GitHub's public API and oneshotagent.dev/facts.json. That last request is logged by our host like any other request to this site. You can turn it off with ONESHOT_FACTS_URL=off.

Your rights

Under the GDPR you can ask for access to, correction of or deletion of personal data about you, and you can object to its use. Apart from the host's short-lived server logs, we hold no personal data. You can also complain to your national data protection authority.
