FAQ

      
What to expect.

    

    

      
Does it track me or send my code anywhere?
No. OneShot only downloads public facts: package versions from npm and PyPI, runtime dates from endoflife.date, Action versions from GitHub, and model lists from Anthropic and OpenAI. Your code stays on your machine. No account, no telemetry. The repo check on this page downloads a public repo to a temporary folder, checks it, and deletes it.

      
Does it only work with Claude?
No. The tools work in any app that supports MCP: Cursor, Windsurf, Codex, Claude Desktop and more. The check before "done" is a Claude Code feature. The CLI and the GitHub Action work with any agent, or none. Our benchmark numbers come from Claude Code with Sonnet; other agents are next.

      
Why not just tell my agent "use the newest versions"?
It helps, but then the agent has to go and look everything up itself. In our test (60 runs each) that was right 54 of 60 times. OneShot hands it the answer in one call: 60 of 60 right, 31% faster and 33% cheaper per run.

      
Will it change my code?
Not by itself. It tells your agent what is current, and the agent writes the code. The GitHub Action only adds notes to pull requests. It fails the check when something will break (a retired model, a runtime with no security fixes); add strict: true to also fail on older versions.

      
Where do the facts come from, and how fresh are they?
From the official sources above, refreshed every 6 hours. Retirement dates come from the providers' deprecation pages. If something looks wrong, open an issue on GitHub and we fix it for everyone at once.

      
What does it cost?
Nothing. It is free and open source (MIT). A paid team plan is planned (alerts before a model retires, one rule set for every repo). It isn't built yet; if you'd use it, tell us what you need. The free tools stay free.
