The project is set up and verified:
- `package.json` has `"type": "module"` and `marked` installed as a dependency.

  - `http://`/`https://` links get `target="_blank" rel="noopener noreferrer"`; relative, `#anchor`, and `mailto:` links are untouched.
- Verified byte-for-byte against vanilla `marked.parse()` output (titles, nested inline formatting, etc. all match except the added attributes), and confirmed slug counters reset between separate `renderMarkdown` calls.
