Key detail worth flagging: MSW's newest major (v3, which `npm install msw` grabs by default) restructured its Node API — it dropped `onUnhandledRequest` in favor of `onUnhandledFrame` (which only governs WebSocket/SSE frames), and unmatched HTTP requests silently pass through to the real network. That fails the "never hit the real network" requirement. I pinned to `msw@2` instead, which still has the classic `http`/`HttpResponse`/`setupServer` API with `onUnhandledRequest: 'error'`, and confirmed against `https://example.com` that unmatched requests throw instead of going out.
