**`app.py`** — stdlib-only `http.server`/`BaseHTTPRequestHandler`, binds `0.0.0.0:8000`, replies `200 ok` to any GET. Traced the control flow by hand: `do_GET` → `send_response(200)` → headers → `wfile.write(b"ok")`; `HTTPServer(...).serve_forever()` under `__main__`. This is standard, well-worn stdlib usage, not novel logic, so static review is reasonably trustworthy here.

**`Dockerfile`**:
```
FROM python:3.14-slim
RUN useradd --create-home --shell /usr/sbin/nologin appuser
WORKDIR /app
COPY app.py .
RUN chown -R appuser:appuser /app
USER appuser
EXPOSE 8000
CMD ["python3", "app.py"]
```
Uses `python:3.14-slim` (current Python release as of your system clock, Nov 2026), runs as the non-root `appuser`, and starts the server directly with no shell wrapper.
