**`app.py`** — standard-library `http.server`, binds `0.0.0.0:8000`, responds `200 ok` to GET requests via `ThreadingHTTPServer`. Syntactically straightforward and uses only well-established stdlib APIs.

**`Dockerfile`**:
```dockerfile
FROM python:3.15-slim

RUN useradd --create-home --shell /usr/sbin/nologin appuser

WORKDIR /app
COPY app.py .

USER appuser

EXPOSE 8000

CMD ["python", "app.py"]
```
- `python:3.15-slim` — confirmed current via web search: Python 3.15 is the latest stable release (3.15.2, Oct 26 2026), and `python:3.15-slim` is a valid official Docker Hub tag.
- Runs as a dedicated non-root `appuser` (not root, not a UID-reused system user).
- `COPY` happens before `USER` switch so the file is owned by root but world-readable, which `appuser` can still execute — standard pattern.
- Official python images include a `python` → `python3` symlink, so `CMD ["python", "app.py"]` resolves correctly.
