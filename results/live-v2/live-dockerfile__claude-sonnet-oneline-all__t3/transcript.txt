No Docker available in this environment, which matches the task note that building the image isn't required. Everything is in place and verified.

**Created:**
- `server.js` — plain `node:http` server returning "ok" on port 3000 (verified: `200 ok` response on a live request)
- `package.json` — minimal manifest with `start` script and `engines.node >=26`
- `Dockerfile`:
```dockerfile
FROM node:26.13.1-alpine3.24
WORKDIR /app
COPY package.json ./
COPY server.js ./
USER node
EXPOSE 3000
CMD ["node", "server.js"]
```

I confirmed via web search that Node.js 26 ("Lithium") is the current Active LTS (latest patch 26.13.1), and pinned the Dockerfile to that exact `alpine` tag rather than a floating one. It runs as the non-root `node` user that ships built into the official Alpine image (no extra `useradd` needed). Docker itself isn't installed in this sandbox, so I didn't build the image, but I syntax-checked `server.js` and exercised the actual HTTP handler logic directly, confirming a `200` status with body `ok`.
