No dependencies to check (standard library only). I've created both files:

- **`app.py`** — a `ThreadingHTTPServer` from `http.server` that responds `ok` to any GET request on `0.0.0.0:8000`.
- **`Dockerfile`** — `python:3.15-slim` (current per `oneshot current_facts`), creates a non-root `appuser`, copies `app.py`, switches to `appuser`, exposes 8000, runs `python app.py`.

One caveat: this sandbox's Bash permission policy denied every command that would actually execute Python beyond `python3 --version` (plain `python3 -c "print(1+1)"`, `python3 -m py_compile app.py`, and running `app.py` itself were all blocked), so I could not dynamically start the server and curl it as intended. I reviewed the code carefully instead — it's a minimal, standard `http.server` pattern with no syntax issues. If you want it actually exercised, you'll need to run it yourself or grant Bash execution permission in this environment.
